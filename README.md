# Asistente Inteligente Comercial - KraftPack Perú

Página web estática tipo infografía/landing page para presentar el Sprint 3 del proyecto de IA Agéntica aplicado a KraftPack Perú.

## Descripción breve

El sitio resume el desarrollo del **Sprint 3: Razonamiento y Herramientas**, enfocado en un asistente inteligente comercial capaz de orientar consultas sobre empaques, papel kraft, bolsas, cajas, envases, productos sostenibles y solicitudes de cotización.

## Sprint correspondiente

Sprint 3: Razonamiento y Herramientas.

## Metodología usada

CRISP-ML + Scrum.

La página muestra la relación del sprint con las fases de CRISP-ML: comprensión del negocio, comprensión de datos, preparación de datos, modelado, evaluación y despliegue. También resume la relación con Scrum: historias de usuario, backlog, desarrollo incremental, pruebas funcionales y review del sprint.

## Archivos incluidos

- `index.html`: estructura semántica de la página.
- `styles.css`: estilos visuales, responsive design y animaciones.
- `script.js`: scroll suave, menú responsive y animaciones de aparición.
- `README.md`: instrucciones del proyecto.
- `assets/kraftpack-packaging.png`: imagen local de packaging kraft para la sección principal.

## Instrucciones para abrir localmente

1. Descargar o clonar la carpeta `sprint3-kraftpack-github-pages`.
2. Abrir el archivo `index.html` directamente en un navegador.
3. No se requiere backend, servidor local, PHP, base de datos ni Streamlit.

## Instrucciones para subir a GitHub Pages

Pasos para publicar en GitHub Pages:

1. Crear un repositorio en GitHub.
2. Subir los archivos `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `assets` si existe.
3. Ir a `Settings`.
4. Entrar a `Pages`.
5. En `Branch` seleccionar `main`.
6. En carpeta seleccionar `/root`.
7. Guardar.
8. Abrir el enlace generado por GitHub Pages.

## Requisitos técnicos

- HTML, CSS y JavaScript puro.
- Sin PHP.
- Sin backend.
- Sin Streamlit.
- Sin base de datos.
- Compatible con GitHub Pages.
